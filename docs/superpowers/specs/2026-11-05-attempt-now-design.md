# Однократная ближайшая попытка

Согласовано: «Попробовать сейчас» снимает только ожидание бюджетного окна и cod. oper для одной отправки. Минимальный интервал между отправками, обновления страницы, HTTP 429 и проверки чистого круга сохраняются. После отправки разрешение расходуется; новый cod. oper снова задаёт паузу. На новый день разрешение не переносится.

Вместо отключения распределения на весь день используем отдельный флаг ближайшей попытки. Действие доступно в меню работы и статистики только для активного профиля, без завершённой передачи управления человеку. В журнале фиксируем причину ручного переноса.

При изменении настроек cod. oper пересчитываем текущую паузу от прежнего начала: первый ответ — от first_cod_oper, последующие проверки — от last_submission. Истёкшая новая пауза разрешает проверку; признак ограничения снимается только обычным ответом сайта.
