# Последовательное ревью PR

Greptile автоматически проверяет новый PR. CodeRabbit запускается отдельным
действием после завершения первого этапа. Исправления в PR сами по себе
не запускают повторное ревью ни у одного бота.

## Проверка исправлений Greptile

После исправлений и push добавьте в PR комментарий `@greptileai`.
Дождитесь опубликованного ревью. Ссылка **Last reviewed commit** должна
указывать на текущий коммит PR. Реакция 👀 сама по себе этого не подтверждает.

Проверьте новые замечания и закройте обсуждения, исправления которых
подтверждены. Закрытие обсуждения само по себе не заменяет новое ревью.

## Запуск CodeRabbit

В GitHub Actions выберите **Request CodeRabbit review → Run workflow**.
Оставьте ветку `main` и укажите номер PR.

Workflow проверит, что PR открыт, последнее опубликованное ревью Greptile
относится к текущему коммиту, Greptile больше не запрашивает изменения,
все его обсуждения закрыты, а обязательные проверки завершились успешно.
Затем он добавит команду `@coderabbitai full review` в обсуждение PR.
Сам workflow отправляет запрос. Результат ревью нужно дождаться отдельно.

Во время перехода между этапами не отправляйте новые коммиты. После новых
изменений снова нужен первый этап. Лимит сервиса или статус Skipped не
считаются успешным ревью.

Новый workflow появится в меню Actions после его мержа в `main`. Для PR,
который добавляет сам workflow, ту же проверку можно выполнить локально:

```sh
python3 scripts/request_coderabbit_review.py --repo itwormz/extranjeria-cita-helper --pr 31
```

Для отправки команды после успешной проверки добавьте `--request`.
Нужны GitHub CLI `gh` и авторизация с правом комментировать PR.
В Actions используется штатный `GITHUB_TOKEN` с правом записи обсуждений PR.
