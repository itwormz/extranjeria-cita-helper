# Справочники приложения

`snapshot-2026-08-12.json` содержит публичные значения списков ICP Plus.
Это ресурс приложения, включаемый в сборку, а не сохранённая пользовательская сессия.

| Справочник | Использование |
|---|---|
| `provinces` | Выбор провинции в редакторе профиля и проверка значения |
| `nationalities` | Выбор гражданства в редакторе профиля и проверка значения |
| `barcelona_offices` | Проверка явно заданного офиса для Barcelona |

Каждый справочник содержит `options` с видимыми названиями (`label`) и
значениями сайта (`value`). Приложение использует названия; при работе с
сайтом выбирает варианты из текущей страницы. Наличие офиса в этом файле
не означает наличие свободной записи. Доступные офисы определяются по сайту.

Снимок получен из HTML страниц 12 августа 2026 года. Дата и источник
указаны в `metadata`. Для обновления нужно сверить публичные списки с сайтом,
обновить JSON и проверить редактор и валидацию профилей. Автоматической
команды обновления справочников сейчас нет.

Персональные данные, cookies, сертификаты и захваты страниц здесь не хранятся.
