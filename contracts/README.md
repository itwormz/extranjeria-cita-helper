# Контрактные эталоны

`fixtures/` — значения, записанные с Python-версии CEH 0.3.6/0.3.7 (бюджет записей, счётчики, журнал,
экспорты, уведомления, профили и т.д.). Rust-тесты сверяют своё поведение с ними. Это замороженные данные.

Скрипты записи (`tests/contracts/*_reference.py`, `regenerate.py`) сохранены в Python-линии `main` (тег `v0.3.8`), в дереве версии
Python; здесь их нет и пересоздавать эталоны не нужно. Если эталон придётся изменить, это решение о поведении
приложения: сначала согласовать с владельцем.
