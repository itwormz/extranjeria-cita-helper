# Security policy

## Reporting a vulnerability

Potential exposure of applicant data, credentials or browser sessions, unsafe
update handling and other security vulnerabilities should be reported privately.
Ordinary website errors or missing appointment availability belong in
[Issues](https://github.com/itwormz/extranjeria-cita-helper/issues/new/choose).
Reports are welcome in English, Spanish or Russian.

If available, use **Security → Advisories → Report a vulnerability** in this
repository. The report is private; do not open a public issue with the details.

If that button is unavailable, open an issue titled **Private contact request**.
Include only a request for a confidential reporting channel. Do not describe the
vulnerability, name affected people or attach evidence until a private channel has
been agreed. This fallback is also available for confidential conduct reports.

A private report can include:

- The affected application version, operating system and architecture.
- A description of the issue and its possible impact.
- Minimal reproduction steps using fictitious data, if available.

Do not send private keys, passwords, session cookies, full browser profiles or real
appointment confirmation numbers. Redact personal information from evidence.
Please avoid testing against other people's data or the live appointment service.

## Supported versions and response

I maintain the latest stable release. Reports about older releases are welcome,
but fixes may be provided only through an update to the latest version. See
[Releases](https://github.com/itwormz/extranjeria-cita-helper/releases).

I maintain this project independently and cannot promise a response or resolution
deadline. I will assess reports when available and coordinate publication of a
confirmed issue with the reporter where possible. There is no paid bug bounty.

[Privacy notes](docs/PRIVACY.md) describe local storage, diagnostics and what to
review before sharing a report.
